## 🎨 Project Overview

**A Little World of Big Ideas** is a colourful, modern, and playful yet sophisticated personal portfolio engineered by **Akhila Xavier**, a B.Tech Computer Science and Engineering student at **Sree Chitra Thirunal College of Engineering (SCTCE), Trivandrum** who completed her first year with an outstanding **CGPA of 9.8**.

Designed around the identity of a **Creative Playground**, the website pairs warm cream backgrounds (`#FAF7F2`) and vibrant geometric shapes (coral pink, lavender purple, sunshine yellow, turquoise blue, and cobalt blue) with authentic academic excellence, hackathon achievements (including **PRISM**, which was **shortlisted by the sponsoring company**), and lightweight static cloud architecture.

## ✨ Signature Creative Playground Features

1. **The 4-Zone Interactive Playground (Replacing traditional navigation)**
   - **Zone 01 — About Me (Lavender Purple):** Educational credentials at SCTCE (9.8 CGPA), CBSE Class 12 IP Topper status, and learning philosophy.
   - **Zone 02 — Tech Superpowers (Turquoise Blue):** Core languages (Python, Java, C, Shell), DBMS, certifications (MACE, GEC Palakkad, Cyber Security), and active frontiers.
   - **Zone 03 — Projects (Coral Pink):** **PRISM** (Hackathon Shortlisted by Sponsor), *Smart Healthcare Companion*, and *A Little World of Big Ideas*.
   - **Zone 04 — Little Things About Me (Sunshine Yellow):** Music, books, swimming, dancing, coding, and continuous curiosity.
   - **Interactive Modal Dossiers:** Clicking any zone reveals an elegant information panel with keyboard `Esc` dismissal and deep section navigation.

2. **Special Interactive Discovery: "Little Things About Me" Shapes**
   - An interactive shape-board where visitors click colourful geometric & organic shapes to reveal personal passions outside of engineering:
     - 🎵 **Music:** Sonic focus and rhythmic clarity during complex logic problem-solving.
     - 📖 **Books:** Broad mental models and diverse perspectives beyond technical syllabi.
     - 🏊 **Swimming:** Physical endurance, breath control, and disciplined iterative technique.

     - 💡 **Learning:** Self-driven exploration into AWS cloud hosting, local AI, and cybersecurity.
     - 💃 **Dancing:** Joyful artistic coordination, balance, and rhythm.

3. **Interactive Developer Console (Playground Shell)**

## 🚀 Local Setup & Testing

### Option 1: Direct File Preview
Double-click `index.html` to open the website directly in any modern browser.

### Option 2: Local HTTP Server (Recommended)
Using Python:
```powershell
# In the project root:
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.
