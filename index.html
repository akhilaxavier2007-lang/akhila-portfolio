Hackathon Shortlisted
01

PRISM — Local AI Privacy Copilot

Python Privacy Engineering Prompt Sanitization Local NLP API Intermediary

An innovative privacy-preserving copilot developed for a competitive hackathon that shields sensitive user data, PII, and credentials before transmission to external AI services.

Hackathon Recognition & Architecture

  • Hackathon Recognition: Fully completed and demonstrated at the hackathon, earning direct shortlisting by the sponsoring company for future incubation and collaboration!
  • The Problem Solved: When developers and students send prompts to commercial LLMs, confidential code, passwords, API tokens, and personal details leak inadvertently.
  • The Engineering: PRISM executes client-side regex and heuristic sanitizers locally, intercepting outgoing prompts to strip or pseudonymize sensitive tokens before API dispatch.
Hackathon Completed • Shortlisted by Sponsor

Smart Healthcare Companion

Java Java Swing AWT JDBC MySQL

A comprehensive desktop healthcare management application designed to streamline patient records, appointment scheduling, and doctor consultation workflows.

Architecture & Implementation

  • Purpose: Replaces chaotic manual clinic paperwork with an intuitive desktop GUI for reception staff and medical practitioners.
  • Desktop GUI: Built with Java Swing and AWT for smooth window management, data entry dialogs, and tabular record views.
  • Database Tier: Integrated with MySQL via JDBC, enforcing relational schema integrity, primary key normalization, and patient record retrieval.
