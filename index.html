Hackathon Shortlisted
01

PRISM — Local AI Privacy Copilot

Python Privacy Engineering Prompt Sanitization Local NLP API Intermediary

An innovative privacy-preserving copilot developed for a competitive hackathon that shields sensitive user data, PII, and credentials before transmission to external AI services.

Hackathon Success & Architecture

  • Hackathon Recognition: Fully completed and demonstrated at the hackathon, earning direct shortlisting by the sponsoring company for future incubation and collaboration!
  • The Problem Solved: When developers and students send prompts to third-party LLMs, proprietary code, passwords, API tokens, and personally identifiable information (PII) leak inadvertently.
  • The Engineering: PRISM executes client-side regex and heuristic sanitizers locally, intercepting outgoing prompts to strip or pseudonymize sensitive tokens before API dispatch.
