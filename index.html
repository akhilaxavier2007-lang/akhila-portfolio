Hello, I am Akhila Xavier — a Computer Science and Engineering student driven by the desire to understand how systems work from the inside out.

Currently pursuing my B.Tech in Computer Science and Engineering at Sree Chitra Thirunal College of Engineering (SCTCE), Thiruvananthapuram, my journey is rooted in an active curiosity about technology and software development.

To me, programming is not just about memorizing syntax or completing assignments; it is a creative medium for transforming raw ideas into practical, reliable tools. Whether exploring object-oriented design in Java, writing structured algorithms in C, or experimenting with modern web standards, I enjoy the meticulous process of taking a problem apart, understanding its constraints, and assembling an elegant solution.

Beyond the terminal, I believe true creativity comes from maintaining a broad perspective. Listening to music, reading thoughtfully, swimming, and exploring new concepts outside the classroom all contribute to how I approach technical challenges with patience, balance, and an open mind.

Academic Application
01

Smart Healthcare Companion

Java Java Swing AWT JDBC MySQL

A desktop-based healthcare management application built in Java designed to streamline patient records, appointment scheduling, and doctor consultations.

Project Details & Purpose

  • Purpose: Solve the clutter of manual hospital paperwork by providing an intuitive graphical user interface for front-desk staff and patients.
  • Architecture: Developed with Java Swing and AWT for desktop window management and interactive input dialogs.
  • Database Tier: Integrated with a MySQL relational database using JDBC for secure storage of patient demographic records and consultation histories.
  • Academic Scope: Focuses purely on core OOP concepts, relational normalization, and client-side validation without misrepresenting AI or cloud capabilities.
Academic Desktop Project (Completed)
Exploratory Concept & Prototype
02

PRISM — Local AI Privacy Copilot

Privacy Engineering Data Sanitization Python Concept API Security

An exploratory project investigating privacy-preserving intermediaries that protect sensitive user data before interacting with external artificial intelligence services.

Conceptual Approach

  • The Problem: When developers and students send prompts to commercial LLM APIs, confidential details, API keys, and personal identifiers can inadvertently leak.
  • The Concept: PRISM explores a local client-side layer that inspects outgoing prompts, detects sensitive patterns (e.g. emails, tokens, personal identifiers), and scrubs or pseudonymizes them locally.
  • Current Status: Early experimental research and prototype stage. Presented honestly as an active investigation into local AI safety rather than a fully finished commercial copilot.
Research & Prototype Exploration (In Progress)
